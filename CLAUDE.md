# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Furry Storm Ticketing Platform (福瑞风暴票务) — a ticketing platform for the Chinese furry fandom event community.

**Current state (April 2026):** The main website is being migrated from Astro to React with Three.js-driven 3D interactions. The only file in this repo is a standalone recruitment landing page (`furry-storm-hiring.html`).

## Planned tech stack

The main website (not yet in this repo) will be built with:

- **React** — UI framework
- **Three.js / React Three Fiber (R3F)** — 3D scenes and interactions
- **Tailwind CSS** — styling
- **Vercel** — hosting and deployment
- **Git / GitHub** — version control
- **AI-assisted development** — Cursor and Claude Code are the primary development tools; the team expects developers to use AI tools competently, not blindly

## Design

- Design tool: Figma with a component/design-token system
- Aesthetic direction: light, slightly futuristic, warm — described as "Rhine Lab × newspaper typography" fusion
- Design system uses tokens and a cohesive color palette (greens, warm paper tones)

## Hiring page

`furry-storm-hiring.html` is a standalone, self-contained recruitment page (no dependencies). It lists two open roles:
1. UI/UX Designer (Figma, component design, design tokens, motion prototypes)
2. Frontend Engineer (React, Three.js/R3F, Vercel, Tailwind, Git, Cursor/Claude Code)

## Team & work style

- Small, remote-first team
- Async communication preferred
- Project-based collaboration, flexible/part-time friendly
- Furry-fandom-friendly environment
